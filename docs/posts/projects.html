Projects!

Introducing my new projects page!

I thought it would be fun to embed the README for some of my projects on my website, so I used Hugo’s resources.GetRemote to download it and strings.replaceRE to point relative links back to the repo (plus some other processing).

The part I’m excited about is the timestamp on the index page though. It is the timestamp of the latest commit for that project, so it’s a quick way to see the recent projects I’m working on. It’s also a good motivator for me to give an old project some love.
