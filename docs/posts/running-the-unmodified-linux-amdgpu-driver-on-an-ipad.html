Running the unmodified Linux amdgpu driver on an iPad

An editor and IDE for iPad with on-device LLM inference on an AMD GPU.

LemonSeed Studio is a single iPad app. It bundles:

  • mac_linuxgpu: the unmodified upstream Linux amdgpu + amdkfd driver, embedded in the app as a PCIDriverKit extension. It drives an AMD GPU in a Thunderbolt enclosure.
  • LemonSeed Engine: the inference engine, running on that GPU through its HSA runtime and HRX/Loom.
  • amdgpu_mtopg: live GPU telemetry.
third_party/mac_linuxgpu   GPU driver (submodule)
third_party/LSE            inference engine (submodule)
third_party/amdgpu_mtopg   GPU monitor (submodule)

git clone --recurse-submodules <repository>

Or, in an existing clone:

git submodule update --init

mac_linuxgpu fetches its own pinned Linux sources sparsely on first build, so its nested kernel submodule does not need to be cloned recursively.
