Collection of preserved UI style guides

Marcin Wichary

26 November 2026 / 79 style guides

This is a collection of preserved UI style guides a.k.a. interface guidelines from various companies, starting from the early 1980s and continuing to today.

Many of the PDFs have been floating around, but I collected them in one place. Within each set, I tried to group them depending on themes and eras, and highlight the most important ones. Some required more effort to find, I scanned a few myself, plus also created standalone mirrors of various minisites. Some of the mirrors were lightly cleaned up to make their consumption easier – stuff like pixellating images better, inlining images instead of linking to them, or fixing YouTube embeds. Enjoy!

  • KDE

    KDE originally stood for K Desktop Environment and is a popular Linux GUI.

  • KDE Human Interface Guidelines

  • PenPoint

    PenPoint was an early tablet operating system developed by GO Corporation for its unsuccessful line of devices.

  • PenPoint UI Design Guidelines

  • Taligent

    Taligent was a troubled software company, incorporated as an Apple/IBM partnership. One of its fruits was a CommonPoint application framework.

  • Human Interface Guidelines

That’s it! Please let me know if you have any thoughts and particularly if you have some style guides that are missing from the above list.
