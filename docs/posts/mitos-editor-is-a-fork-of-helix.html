Mitos editor is a fork of Helix

Mitos is a batteries-included modal text editor built around selections, with multi-cursor, tree-sitter syntax awareness, and built-in language tooling.

Features

Selections and multiple cursors

Select text, then apply an operation. Use multiple selections to edit several locations at once.

Language Server Protocol (LSP)

Completion, diagnostics, go-to-definition, rename, formatting, and code actions through configured language servers.

Tree-sitter

Syntax highlighting, syntax-aware selection, and text objects for navigating and editing code.

Debug Adapter Protocol (DAP)

Set breakpoints, step through code, and inspect variables with a configured debug adapter.

Image previews

Open image files and preview them directly in the terminal.

File navigation and search

Browse directories with the file explorer, find files with the file picker, and search across the workspace.

Why fork Helix?

Helix built a strong foundation. Mitos is a chance to build on it at a faster pace, experiment with new features and different approaches to the architecture, and see where it can take us. For now, expect less stability and occasional breaking changes. Nevertheless, the end goal is similar - fast, robust, and extensible editor for all your needs.
