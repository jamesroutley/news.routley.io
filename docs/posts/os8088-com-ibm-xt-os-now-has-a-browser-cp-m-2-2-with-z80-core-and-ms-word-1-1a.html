Os8088.com: IBM XT OS now has a Browser, CP/M 2.2 with Z80 core and MS Word 1.1a

August 2026

Six additions in one month, each with what it still will not do.

AUG 2026 Networking

Browser

A web browser for the IBM PC XT

Real pages over a parallel cable, without HTTPS.

os8088 now fetches real web pages and lays them out as text and tables, over an Ethernet card or a parallel cable to a DOS machine standing next to it. The network is not the slow part: drawing a window full of text takes longer than fetching the page. There are no images and no JavaScript, and the browser refuses https:// addresses by name -- opening an encrypted connection is one very large multiplication, and this processor takes minutes over it. A helper program on another machine does that part.

  • 13,889-byte browser
  • ARP to TCP stack
  • 4.77 MHz 8088

AUG 2026 Ported software

RunCPM

CP/M, in a window

A 1979 operating system on a processor it was never written for.

CP/M was the operating system small computers ran before the IBM PC existed, on a processor the PC does not have. os8088 now emulates that processor, so CP/M software runs here: the 1979 command processor at the prompt, Microsoft BASIC, an assembler and an editor, in a window you can drag like any other. Colour and bold arrive from the software and are ignored: the screen underneath is black and white, with one typeface.

  • Emulates a Zilog Z80
  • 4,679 lines of C
  • 4.77 MHz 8088

AUG 2026 Languages

CWORD

A word processor written in C

The first program here not written in assembly, and too big to fit in one piece.

os8088 is written in assembly language, one processor instruction at a time. A C compiler now sits in the toolchain, and CWORD is the first program out of it: a second word processor, reading and writing RTF files. C spends memory to save typing -- the same work takes two to three times the room assembly does -- so CWORD does not fit the 60KB a program gets, and ships in two pieces. The half that runs while you type stays in memory; the half behind the menus waits on the disk.

  • 8,350 lines of C
  • 54,450-byte program
  • 4.77 MHz 8088

AUG 2026 Word processing

Microsoft Word

Microsoft Word, on an 8086

The 1990 menus, with no printer behind them.

os8088 now runs a word processor built to look and behave like Microsoft Word for Windows 1.1a, written against the source Microsoft released to the Computer History Museum in 2014. It carries the 1990 menus and dialogs, and gets bold out of one 8x8 typeface by drawing each letter twice, a dot apart, as the original did. It is a new program in assembly, not Microsoft's code recompiled. Of its 85 menu items, 57 are gray: nothing on os8088 can print yet, and the dictionaries were never in that source.

  • 47,212-byte program
  • Saves Word .DOC files
  • 4.77 MHz 8088

AUG 2026 Graphics

Two monitors

Two monitors, one desktop

One desktop across two cards, and it stops at two.

A PC of this era could hold a monochrome card and a colour card at once, because their picture memory sat at different addresses. Almost nothing used both together. os8088 now spans one desktop across the pair, and a window that lands over the join is drawn on both screens. The menu bar, dock and drive icons stay on the main monitor; the second screen is extra room and nothing else. It needs a real Hercules card and a real CGA card, and it stops at two.

  • Two monitors, two cards
  • Desktop, 1,360 x 348
  • 4.77 MHz 8088

AUG 2026 Games

Frotz

os8088 plays Infocom games now

Story files from 1982, without their pictures.

Frotz is a Z-machine interpreter written in 8086 assembly. The Z-machine is the pretend computer Infocom invented in 1979 so one game could be sold for every machine at once, which is why a story file from 1982 is still a plain file that still runs. Mini-Zork, Colossal Cave Adventure, Zork: The Undiscovered Underground and Photopia all play, off a floppy of their own. Timed scenes are told to take their untimed path, and the illustrated games arrive without their pictures.

  • 23,722-byte interpreter
  • Story formats v1 to v8
  • Fetches 15 games
