Treemap of the Riemann Hypothesis Lean Proof

On 20 November 2026 Levent Alpöge released a Lean 4 formalization, written with Claude, that states and proves the Riemann Hypothesis and its generalization to Dirichlet L-functions. The source is 175,187 modules (a module is one .lean file). This page shows what is in them.

The statement

These two files are the whole claim. Statements.lean defines four propositions. Main.lean proves them, and Mathlib's own RiemannHypothesis, by citing theorems from the other 175,185 modules. Point at a symbol to see how to say it and what type it has.

In words: every zero of the Riemann zeta function, other than the trivial zeros −2, −4, −6, … , has real part ½. For every Dirichlet character χ, every zero of L(s, χ) with real part strictly between 0 and 1 has real part ½.

      Sources and method

      • The Lean source is from Alpöge's announcement. The page reads it from the mirror 1337isnot1337/riemann-hypothesis-solved at commit 6193bb5. The archive declares no licence, so this site does not store the Lean files; it stores module names and counts, and loads code from the mirror when you open a module.
      • All counts on this page come from a script that reads every file once. Its totals match the independent checks above: 175,187 files, 17,374,215 lines, longest import chain 203.
      • Declarations are counted by matching keywords such as theorem and def at the start of a line. Lean's kernel sees more declarations (1,484,729 in the nanoda runs) because Lean generates auxiliary ones.
      • The proof steps on the map follow jae-63's blueprint, which matched Alpöge's timeline to Lean names by search and partial reading. It is one reader's interpretation.
