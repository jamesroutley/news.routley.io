Introducing Facet: My first audio plugin

I’m proud to have reached the point where my audio plugin framework, Lindale, is capable of shipping ‘real’ audio plugins. The first of these is Facet.

Introducing Facet

Facet is an audio visualizer and analysis tool that combines some standard views for analyzing sound, a peak/RMS meter, spectrum analyzer, and stereo goniometer, with a more unusual hilbert transform view, visualizing the incoming audio signal in complex space.

This plugin is open source and MIT licensed, and mainly a proof of concept for the plugin framework.
