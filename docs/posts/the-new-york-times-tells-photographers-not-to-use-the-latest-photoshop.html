The New York Times tells photographers not to use the latest Photoshop

The paper is requiring freelance photographers to stick to older versions of the software.

The New York Times, a major newspaper in the US, has told freelance photographers that they aren’t allowed to use the latest version of Photoshop as “certain functions” can “utilize generative AI in ways that may not be apparent to users.” The email, posted to social media and confirmed by The Verge, says this can lead to “metadata identifying photographs as AI-generated.”

That last bit is important, as an AI warning showing up a news outlet’s photo on social media would likely stir some controversy. That’s especially true if that outlet has publicly said it won’t use AI-generated images when reporting the news.

Most photographers don’t need to worry about the New York Times‘ editorial standards, but there can sometimes be social repercussions for posting an image identified as having been made or edited using AI (platforms typically don’t differentiate between minor edits and wholesale generation). As AI-powered tools become more pervasive and integrated into apps and operating systems, there have been several examples of people being caught out, wondering why their images were flagged, not realizing that whatever tool they were using utilized generative AI.

Of course, that tech didn’t just show up in the latest version of Photoshop. For several years, features like the Remove tool or Generative Fill have been able to use generative AI. While the app is generally upfront about which features use the tech, it’s undoubtedly crept into more and more places, including Adobe Camera Raw, which is meant for processing Raw images. While the Times is typically quite strict about making any alterations to photos, it’s possible the outlet has run into issues with people submitting photos altered by AI, then later claiming ignorance.

The policy shared says that “at this time” contributors aren’t allowed to use the latest version of Photoshop, which could suggest that the company is working on guidance that would allow its use in the future. While not every creative company is as all-in on AI as Adobe, there are few photo editing tools these days that don’t include at least a few generative AI-powered features.
