What Cloudflare Doesn't Tell You

Cloudflare has arguably done more to push modern internet technologies than any other company. The work they have done to enable TLS, IPv6, post quantum encryption, and other modern standards for millions of websites deserves a tremendous amount of credit.

While this is great, Cloudflare also hides many of the shortcomings of the underlying infrastructure from both users and website owners. Yes, you can connect to a Cloudflare website and it'll allow for IPv6, post quantum encryption, and TLS. But Cloudflare's connection to the origin server might be entirely unencrypted and rely exclusively on IPv4. This creates a huge mismatch between what is being presented to users and the reality of the connection.

One of my biggest problems with this is the fact that Cloudflare doesn't do enough to notify website administrators about these issues. While Cloudflare provides tools to inspect these, comprehensive visibility is lacking. The Cloudflare dashboard should notify you about each of these issues where Cloudflare is following better practices than your origin server, without website administrators having to dig through and specifically look for this information. Clear warnings and proactive alerts to administrators would help greatly.

Not only that, but according to Cloudflare's own documentation, they actively prefer IPv4 over IPv6 when making origin server requests, which is particularly disappointing for a company that has done so much to advance IPv6 adoption:

For proxied DNS records that have both an IPv6 and IPv4 origin address, Cloudflare will prefer the IPv4 address when connecting to your origin server.

Even when website administrators invest in deploying IPv6 on their origin servers, Cloudflare still prioritizes IPv4.

I also believe the industry should consider adding functionality so CDNs and other intermediate networks can expose origin TLS connection information alongside their own. This would allow users and network researchers to better understand the encryption state of the entire path and hold website owners accountable for bad security practices. A similar mechanism could expose which IP version is being used to communicate with the origin server.

Cloudflare has an opportunity to not only make modern internet technologies accessible to users, but also encourage adoption of those technologies throughout the underlying infrastructure. Cloudflare should be a catalyst for modernizing the internet, not a mechanism that allows website owners to avoid modernization indefinitely. Improving transparency would be a meaningful step toward achieving that goal.
