KetchUp – Open-source SketchUp alternative built with Rust and WebGPU

BenchUp is a free, open-source 3D modeling app for woodworking and furniture design. Plan a shelf, table, cabinet, or workbench with exact measurements before you build. Use it on Windows, macOS, Linux, or right in your desktop browser.

Free & open source. No account needed.

Plan your furniture

For woodworkers, furniture makers, and DIY builders who want to explore a project in 3D.

Model the pieces

Draw board outlines with rectangles and lines, then use Push/Pull to give them thickness. Move and copy geometry to explore shelves, tables, cabinets, workbenches, and other furniture.

Check dimensions and fit

Enter exact lengths, snap to geometry and axes, and use Tape Measure and Dimensions to inspect your design. Orbit around the assembly to review proportions before taking it to the workshop.

Keep the project organized

Use groups, reusable components, and tags to organize parts. Save a portable .ketchup project locally, import SketchUp geometry, or export OBJ geometry for another 3D workflow.

  3. Find a fresh perspective

A few things

What do I need to run it?

A desktop browser with hardware acceleration and WebGPU or WebGL2 support. Use a mouse and keyboard for modeling. You can also run BenchUp as a native Windows, macOS, or Linux app.

Where does my work go?

Your model is autosaved in this browser on this device. Use File → Save to download a .ketchup project you can keep or open again. Clearing browser data can remove autosaved work, so download projects you want to keep. There’s no cloud storage or account to set up.

Can I use my existing models?

Use File → Import/Export to import SketchUp (.skp) geometry or export Wavefront OBJ (.obj). Imports run locally. SketchUp textures, scenes, and some model features aren’t supported; OBJ export includes geometry without materials.

Is BenchUp free?

Yes. BenchUp is open source under the MIT license and written in Rust. Explore the code, read the full guide, or contribute on GitHub.
