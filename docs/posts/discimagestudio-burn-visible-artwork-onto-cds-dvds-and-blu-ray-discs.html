DiscImageStudio: burn visible artwork onto CDs, DVDs and Blu-ray discs

简体中文 | 繁體中文 | English | 日本語

全能的光盘盘面可见图像生成与刻录工具

Disc Image Studio 是一个多平台的光盘盘面图像生成与刻录工具，帮助您使用任何刻录光驱在任何 DVD / CD / 单层蓝光 光盘上刻蚀出肉眼可见的图像。

Disc Image Studio 可将一张图片转换成符合 CD、DVD 与单层 BD-R 光盘物理层约束的数据，刻录后将使光盘盘面呈现肉眼可见的图案。

Windows 下载 win-x64.exe 后可直接运行。Linux 或 macOS 请下载与 CPU 匹配的实验性 CLI 压缩包，解压后运行 ./disc-image-studio --help。这些发布包均自带 .NET 运行时。 GitHub Releases

在主页选择 CD、DVD 或蓝光，指定输出位置后创建工程。

在设计页导入图片，用图层完成排版，并在右栏「影调」模块调整抖动、伽马、亮度与灰阶档位。

在预览页核对盘面投影，在导出页生成 ISO / RAW / WAV+CUE，或使用即时刻录功能直接写入空白盘片。

即时刻录为实验性功能，请只使用可报废的测试介质。

  • CD 支持：支持任何 CD 。您可导出带格式头的 WAV 音轨及配套 CUE，兼容 cdrecord, ImgBurn等刻录软件；也允许导出 RAW 音轨。详见 CD 刻录兼容说明。
  • DVD 支持：支持任何 DVD。您可导出 ISO 镜像。
  • 蓝光支持：支持任何单层 BD-R 25 GB，支持纯绘图与 UDF 2.01 文件。详见 ADDING_BLURAY.md。
  • 随盘文件：CD／DVD／蓝光可在设计页直接选择要保存的文件夹及内圈／外圈位置，也可在导出页调整；设置随工程保存。
  • 文件区域预览：混合盘的设计投影和成品读回用黄色标出文件区（含文件系统）。
  • 介质灰度方案：CD 与 DVD 均使用黑白二阶，CD 使用 0D / AA，DVD 扰码域使用 A5 / 92。详见 PHYSICAL_MODEL_AUDIT.md。
  • 灰度抖动工具：独立程序也可将原图处理为 0/255 黑白二阶 PNG；支持打开或拖入原图、并排预览及无损 PNG 导出。详见使用与构建说明。
  • 盘片预设：内置数个品牌的光盘参数，覆盖 CD／DVD／BD。您也可将自己标定好的数据贡献给我们，详见预设维护说明。

Disc Image Studio 提供了一套智能且精准的辅助标定流程，相较人工肉眼识别标定，辅助标定算法将可确定的盘面物理数据精确度从 10-6 提升到了 10-14。校准前采用恒定轨距，十字线的径向线条出现明显弯曲；使用辅助标定得到的三次轨距参数重新生成并刻录后，线条更接近径向直线。

  • 镜像文件输出：您可以导出完整 ISO / RAW 文件并使用合适的刻录软件手动刻录。
  • 即时流式刻录（实验性）：CD、DVD 与 BD-R 边生成边刻录，不保存完整镜像；BD-R 走 MMC 顺序写入。
  • 不要使用非空白介质！
  • 桌面版需要 Windows 10 2004（2004/20H1，19041）及以上，或 Windows 11。
  • 构建：.NET 10 SDK（global.json 锁定 10.0.x）；自行构建的非自包含 GUI 需要 .NET 10 Windows 桌面运行时。Release EXE 已包含运行时，无需另行安装 .NET。
  • “即时刻录”功能需要一台 Windows 可识别的 CD / DVD / BD 刻录机与空白盘片；BD-R 需要支持顺序写入的单层空白盘。
dotnet build DiscImageStudio.slnx --configuration Release
dotnet run --project src/DiscImageStudio.App --configuration Release

构建回归检查：

dotnet run --project src/DvdImageSolver --configuration Release -- selftest
dotnet run --project tests/DiscImageStudio.ArchitectureTests --configuration Release

版本规则、CI 生成 EXE、Release 草稿检查、MSIX 打包与签名流程见发布指南。

Linux（glibc）可选 linux-x64 或 linux-arm64。Apple Silicon Mac 选 osx-arm64，Intel Mac 选 osx-x64。CLI 在本地生成镜像，实际写盘可交给支持相应镜像或音轨的刻录软件。

使用 .NET 10 SDK 从源码运行 CLI

dotnet run --project src/DiscImageStudio.Cli -c Release -- --help

CLI 可读取 PNG、JPEG、BMP 和 GIF，使用动画图片的第一帧。下面的例子用两扇区音轨验证安装，同时生成配套 CUE。

./disc-image-studio cd-generate --input picture.png --output sample.wav --sectors 2

Disc Image Studio 的实现与物理模型主要参考以下规范：

介质 标准与版本 本项目采用的范围
CD-R ECMA-394，第 1 版，2010 年 12 月 — Recordable Compact Disc Systems CD-R Multi-Speed（官方 PDF） CD-R 介质、多速录制及 CD-DA 兼容关系；本项目生成 CD-DA 音轨。
DVD 公共格式 / DVD-ROM ECMA-267，第 3 版，2001 年 4 月 — 120 mm DVD – Read-only disk（官方 PDF） DVD 数据帧、ECC、EFMPlus 编码及附录 G 转换表；可记录盘的介质规则另参考 ECMA-359。
DVD-R ECMA-359，第 1 版，2004 年 12 月 — 80 mm (1,46 Gbytes per side) and 120 mm (4,70 Gbytes per side) DVD Recordable Disk (DVD-R)（官方 PDF） 单层 DVD-R 的几何、扇区、纠错和编码；标准包含单面及双面介质，双面不等于双层。
BD-R ISO/IEC 30190:2021，第 3 版，2021 年 1 月 — 120 mm 单层（25.0 GB）及双层（50.0 GB）可记录 BD 的信息交换与存储规范 实验模式采用单层 25 GB 的轨道、扇区布局、纠错和编码；目前不支持双层盘。

CD 公共编码部分还参考了 ECMA-130，第 2 版（CD-ROM，1996）。

刻录与介质安全须知

  • Disc Image Studio 不安装驱动或服务；“即时刻录”功能使用了 Windows 自带的 IMAPI2，拒绝非空白介质。
  • “即时刻录”功能已有部分实盘反馈，对不同设备、介质与刻录入口的验证覆盖仍有限，属于实验性功能，请只使用可报废的测试介质。刻录中断、断电或生成速度不足仍可能使盘片报废！
  • 实际可见效果取决于盘片、刻录机、固件与写入策略。
  • 混合文件夹会在开始刻录前扫描目录并固定布局；期间源文件大小改变会安全终止任务，已开始写入的盘片仍可能报废。
  • BD-R 顺序写入不提供备用区重映射；中断后同一盘片通常不能继续写入。
  • Disc Image Studio 不联网、不上传文件、不收集遥测，详见隐私政策。
  • 发现安全问题请不要在公开 Issue 中披露，按安全政策使用 GitHub 私密报告。
