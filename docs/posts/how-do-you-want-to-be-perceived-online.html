how do you want to be perceived online?

following up on yesterday's post i remembered lola odelola's amazing talk what do you see?, about what the web could be like if we centered screen reader and alt-text users.

this talk and another project she mentions in it, alt text selfies, remind me that there are great amounts of ingenuity and dimensionality to the web with the tools we have at our disposal already.

i love elle's homepage, built with partyKit/cursorParty on the highly visual end of expression.

i like whimsica11y, a project by sara joy (whose site feels almost tactile to me, nearly hitting every sense possible on the web in this post!), to help make the joyful sites of the freewheeling web more accessible.

melon's site is a blast from an alternate past webwise, an audiovisual experience!

i think i do want to explore some kind of javascript library that allows you to have an interactive audio layer on a blog, so if that kind of thing exists or you would like it or like to help make it, feel free to reach out as ever!

how do you like to be sensed online? are you happy being all picture, word and video or some combo therein? let me know!

this is my twentieth post in my writing month challenge, which i decided is "one post for each day of november".
