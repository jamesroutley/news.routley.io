should learning to code be like learning to read?

last updated 2 days ago

working through my thoughts to one of my own questions today, namely:

is "the use of technology" a thing like "learning to read", where if it's possible you should always have the ability to do it? i'm sure that's where the "teach every child to code!" benevolent impulse comes from... loads of them just want money for their programs/hardware/software/pockets sure, but a lot also think that the future will be technical, and we should put people in the best stead for that. writing out the question, i think i don't believe it's like reading, but i would love to hear other takes.

learning to code isn't like learning to read because...

  • i don't think anyone has "failed" a child who never picks it up or takes an interest in it in their lifetime?
  • there's loads of stuff that computers and coding just don't touch currently
    • many other arenas where code would actively worsen the experience, but i digress and also have complained enough!
  • it's not a skill that you must pick up in order learn a bunch of other skills in the way reading is
  • more of a nice to have for most people
  • you need to be able to read to code (in most cases; things can be read out to you)
  • it takes a lot of learning to get to the point you can do much unless you are very interested
  • feels like part of STEMification of everything, and a devaluing of other cool and useful skills

learning to code is just like learning to read because...

  • i assume lots of these styles of arguments were made when and for a long time after the printing press was invented (though i'm unsure computers have changed life fundamentally in the same way, i wouldn't bet my life on it as an erstwhile and even then only sometime fan of studying history lol)
  • it does unlock some opportunities and cool experiences
  • everyone should have the chance to learn the skills to mould what they have to use everyday
  • no one really gets a "choice" in what they learn in school in the preliminary stages, (if they go!) so it should be another topic on the curriculum from an earlier age so people are more exposed to it earlier.

what do you think? is coding like reading aka important in a way that it can't be left off curriculums? does AI change how you feel about this? let me know!
