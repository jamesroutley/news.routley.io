The Kio Programming Language

For almost as long as I've been programming, I've had an aspiration, held with varying degrees of seriousness, of creating a programming language of my own. Unfortunately, however, creating a programming language is an expensive hobby at an estimated cost of a two-year sabbatical and one hammock—and so I wasn't sure if I would ever get around to it.

Two things happened recently that helped me realize this aspiration.

First there was the Iran War, which led me to take a sabbatical from my job in Dubai. Second, LLMs got to the point where they are genuinely good at coding.

So for the past three months I've been vibe coding a programming language.

I know, I know. It sounds like a really terrible idea. But I had a ton of fun and I'm actually quite happy with the result. Happy enough that I'm now making this project public.
