Dutch National Cyber Security Center is Offline because it uses PHP

Vanwege de kwetsbaarheden in PHP hebben wij uit voorzorg onze website (NCSC.NL) tijdelijk offline gehaald. We werken hard aan een oplossing en doen er alles aan om de website zo snel mogelijk weer beschikbaar te maken. Voor actuele informatie over deze kwetsbaarheden verwijzen we je graag naar onze pagina op de NCSC Community.

Patch om 16:00 uur verwacht

Het securityteam van PHP heeft een patch aangekondigd. De patch staat gepland om 16:00 Nederlandse tijd. Binnen een uur na het uitkomen van de patch verwachten we een advisory te publiceren op advisories.ncsc.nl.

NCSC-pagina op Github

Daarnaast heeft het NCSC een pagina ingericht op Github. Hier vind je technische informatie over de kwetsbaarheden. Deze pagina wordt doorlopend geüpdate door het NCSC. Op dit moment wordt er gewerkt aan een inventarisatie van alle PHP-gerelateerde softwareproducten om inzichtelijk te maken welke producten kwetsbaar zijn.

Overige informatie

In de tussentijd kun je ook voor nieuws, updates of vragen terecht op onze LinkedIn-pagina en de NCSC Community. Organisaties die gebruik maken van onze CSIRT-dienstverlening kunnen terecht op MijnNCSC.

Onze excuses voor het ongemak en bedankt voor je begrip.
