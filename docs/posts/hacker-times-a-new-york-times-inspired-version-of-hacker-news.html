Researchers Report Direct Edits to Neural-Network Weights

An MIT CSAIL team reports that Astra improved Qwen’s math scores by editing weights using Python and feedback from practice runs. In the test allowing 50 forward passes, the authors report MATH-500 rising from 7.9% to 48.1%. These preliminary results are separate from the team’s raw-weight-only experiments on smaller networks.

Andrej Karpathy Builds a Video Library From Hacker News Recommendations

HackerTube gathers 6,454 YouTube videos mentioned by Hacker News readers across nearly two decades. Karpathy describes using AI coding tools to build an alternative browsing experience, with its own recommendations and no user accounts.

A Critique Draws a Line Between Astra’s Weight Experiments

A critique on honnibal.dev argues that the Astra report groups together experiments using different methods. It distinguishes small-network tests based on raw weights from the Qwen work, which used Python and model runs, and challenges treating them as evidence of a single technique.

An Earlier Report Questions Ubuntu’s Kernel-Patch Delay

In an October 31 article, freenode news reported that Ubuntu’s 22.04, 24.04 and 26.04 LTS releases still lacked kernels patched for CVE-2026-98432. This is the report’s account, not a fresh verification of Canonical’s current patch status.

Central Warsaw, Rebuilt One Voxel at a Time

The project presents a three-dimensional model of central Warsaw assembled from OpenStreetMap, LiDAR and the city’s tree database, with a voxel resolution of one meter.

A Backstage Glimpse of the Windows 2000 Launch

In a Microsoft blog recollection, the author describes slipping into an early rehearsal and learning that Patrick Stewart would host the Windows 2000 launch. A headset-wearing crew member stood in for the actor during the run-through.

Klang Finds a Token Premium for Nordic Languages

Klang Research reports that Swedish, Norwegian, Danish and Finnish translations required more tokens than English in its tests. Using two parallel-text datasets, the study links the gap to how tokenizers split text and finds smaller premiums with a Nordic-focused tokenizer.
