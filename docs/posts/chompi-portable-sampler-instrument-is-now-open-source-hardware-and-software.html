Open Source Files

This is a discontinuation open-source release: a permanent source for the files and documentation, and it will likely not be receiving updates. To customize it, clone the repo into your own GitHub. This repository holds the original source files for hardware and software – including blank enclosure panels – that make up the CHOMPI Mk1. All CHOMPI artwork has been excluded.

Wavetable Synthesizer

As part of our Open Source release, we’ve included a beta release of a fun firmware exploration. WAVE is an 8-voice wavetable synthesizer that runs on your CHOMPI. Parts of WAVE will feel familiar if you’ve spent time with TAPE or TEMPO, but it’s also its own thing — intentionally stripped back, while still maintaining a bit of CHOMPI flavor throughout.

    • firmware/chompi-tape: TAPE 2.0, the sampler firmware every CHOMPI ships with.

    • firmware/chompi-tempo: TEMPO 1.0, a pattern generator firmware — the counterpart to TAPE.

    • firmware/chompi-wave: WAVE 1.0, a wavetable synth firmware that doubles as a starting point for anyone writing their own firmware.

    • firmware/chompi-bootloader-v6.4-beta: The bootloader. Never shipped on units, which run v6.2; created to improve stability. Abeta.

    • firmware/card-profiles: The factory microSD card contents for TAPE, TEMPO, and WAVE — firmware, samples and settings.

    • hardware/hardware-pcb: Schematic, BOM, EAGLE PCB files, and the full fabrication package.

    • hardware/hardware-enclosure: The six PCB panel enclosure files, as well as laser cutting files for DIY panels.

  • Copyright and Trademark elements:
