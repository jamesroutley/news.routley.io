Website update

With everything in the world reporting security issues last week (php vulnerability, nodejs vulnerability, an SSL key that was the number 4), I decided to upgrade my website.

  • Python 3.6 → 3.13
  • Django 1.11 → 6.1 😱
  • MariaDB → SQLite

I started this blog with MySQL (which I pronounce like “my sequel”) and continued with MariaDB when I moved to OpalStack for web hosting. However, when a database is a couple megabytes and I’m the only person writing to it, SQLite does very well.

A quick performance test showed a 5–16 ms improvement, shaving off roughly 10–30% of server time depending on how much the endpoint relied on database calls.
